# My agent: collector-assistant
One-liner: A conversational agent that helps collectors browse, track, and appraise items with a catalog of collectible marketplace goods.

Tool coverage:
- Memory: User's personal collection, wishlist / grail items, preferred condition grades, and budget
- Tools: Search marketplace listings, check price history and market values, add items to wishlist or collection
- Catalog/UI: Collectible items catalog rendered as rich cards (condition, price, images) and inventory tables
- Image gen: Generate custom collectible showcase art, card mockups, or collection display showcases
- Sandbox: Portfolio valuation, profit/loss calculations on past trades, and market trend regressions

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for portfolio valuations, Cloud Trace
